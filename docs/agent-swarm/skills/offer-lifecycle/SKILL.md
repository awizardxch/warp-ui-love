# Skill: offer-lifecycle

> Concrete values (puzzle hashes, wallet IDs, fee amounts) are in `IMPLEMENTATION_CONSTANTS.md`.

## Purpose
Create, parse, and validate Chia offer payloads for all bridge operations.

## Use When
- A bridge flow needs a new offer generated by a Chia wallet.
- A user pastes a manual offer string and it must be parsed.
- The system needs to prepare `createOfferParams` for wallet execution.

## Do Not Use When
- Spend primitives are already parsed and only message/signature processing remains.
- The task is purely EVM transaction assembly.

---

## Wallet Adapter Summary

Three registered wallets in `walletConfigs`:

| id | Name | Mechanism |
|----|------|-----------|
| `sage` | Sage | WalletConnect via @walletconnect/sign-client |
| `goby` | Goby | Browser extension `window.chia` — **NOT WalletConnect** |
| `chiawalletconnect` | Ozone | WalletConnect via @walletconnect/sign-client |

**Goby is a browser extension.** It does NOT use WalletConnect. Calling WalletConnect methods for Goby will fail. Goby uses `window.chia.request()`.

## createOfferParams Shape

```typescript
interface asset {
  assetId: string   // CAT TAIL hash (hex). Empty string "" = XCH
  amount: number    // integer mojos
}

interface createOfferParams {
  offerAssets:   asset[]   // what the wallet offers
  requestAssets: asset[]   // always [] in current bridge flows (no asset request)
  fee: number              // mojo fee integer
}
```

## Sage WalletConnect

```typescript
// Method called: "chia_createOffer"
// Adapter in wallets/sage.tsx hardcodes fee: 2500000000 (0.0025 XCH)
// Custom localStorage prefix: "sage-wc-data"
// Connect method: "chia_getAddress"

const offerString = await sageClient.request({
  topic: session.topic,
  chainId: "chia:mainnet",
  request: {
    method: "chia_createOffer",
    params: { offerAssets, requestAssets, fee: 2500000000 }
  }
})
```

## Ozone WalletConnect

```typescript
// Methods: "chia_getCurrentAddress", "chia_getWallets", "chia_createOfferForIds"
// Custom localStorage prefix: "chia-wc-data"
// Wallet lookup: calls chia_getWallets first to find wallet_id for each assetId

const wallets = await client.request({ method: "chia_getWallets" })
// wallets.data = [{ id, type, name, data: { assetId? } }, ...]
// Find wallet_id by matching assetId; XCH wallet is type 0 or assetId absent

const offerString = await client.request({
  method: "chia_createOfferForIds",
  params: { offerAssets: assetsByWalletId, requestAssets, fee }
})
```

### parseXCHOffer
```typescript
async function parseXCHOffer(offer: string): Promise<[
  CoinSpend[],    // coinSpends
  string,         // aggSig (hex)
  Coin,           // securityCoin (ephemeral, bound by tempSk)
  SExp,           // securityCoinPuzzle
  any             // tempSk (BLS private key)
]>
// Use when: XCH-only offer (no CAT spend in bundle)
// Security coin: ephemeral coin with random tempSk, adds binding sig to bundle
```

### parseXCHAndCATOffer
```typescript
async function parseXCHAndCATOffer(offer: string): Promise<[
  CoinSpend[],    // coinSpends
  string,         // aggSig (hex)
  Coin,           // securityCoin
  SExp,           // securityCoinPuzzle
  any,            // tempSk
  string | null,  // tailHash — null for XCH-only, hex TAIL hash for CATs
  Coin,           // catSourceCoin
  Coin            // catSourceCoinLineageProof (prev coin info)
]>
// Use when: CAT-inclusive offer (lockCATs, burnCATs, mintCATs, unlockCATs all call this)
```

## Offer Asset Construction for Bridge Flows

### Chia → EVM (lockCATs / burnCATs)
```typescript
// User is offering CATs or XCH to be locked/burned
offerAssets = [{ assetId: token.assetId, amount: mojoAmountAfterFee }]
// For XCH: assetId = ""
// For CAT: assetId = token.assetId (CAT TAIL hash hex)
requestAssets = []
fee = 2500000000  // set by Sage adapter; pass desired fee for Ozone/Goby
```

### EVM → Chia (mintCATs / unlockCATs)
```typescript
// User is offering XCH toll + fee for the Chia-side acceptance tx
offerAssets = [{ assetId: "", amount: messageToll + txFee }]  // XCH for toll
requestAssets = []
fee = 2500000000
```

## Protocol Fee Calculation

```typescript
const FEE_RATE = 30n        // 30/10000 = 0.3%
const FEE_DENOM = 10000n

const protocolFee = (amount * FEE_RATE) / FEE_DENOM
const outputAmount = amount - protocolFee

// Minimum: outputAmount >= 1 mojo, protocolFee >= 1 mojo
// Enforced at UI level before calling createOfferParams
```

## Error Cases

| Error | Cause | Action |
|-------|-------|--------|
| Wallet not connected | `walletConnected === false` | Prompt wallet connection |
| `window.chia` undefined | Goby extension not installed | Show install link |
| WalletConnect session expired | Stale session | Re-connect (disconnectWallet then connectWallet) |
| Offer parse failure | Invalid/corrupt offer string | Surface parse error; offer may be for wrong network |
| tailHash mismatch | Offer is for different CAT | Reject; inform user of expected token |
